# Controller 四个固定接口规范

每个 Controller 必须实现以下四个固定接口，鲁班框架通过这四个接口驱动页面渲染和表单交互。

## 四个接口说明

| 接口名 | 路由 | HTTP方法 | 说明 |
|---|---|---|---|
| `getFormUris` | `GET /{path}` | GET | 返回其他三个接口的相对路径名称，固定调用 `Base.successForm()` |
| `formId` | `GET /{path}/formId` | GET | 返回表单命名 ID，格式为 `{name}_form` |
| `validate` | `POST /{path}/validate` | POST | 表单参数校验，通过返回 `null`，失败返回 `{errors:{字段: 错误信息}}` |
| `build` | `GET /{path}/build` | GET | 核心接口：构建并返回完整页面 JSON 结构 |

## 代码模板

```typescript
import { Body, Controller, Get, Post, Query } from '@midwayjs/core';
import { ApiBearerAuth, ApiOperation } from '@midwayjs/swagger';
import { Base } from '../commons/Base';
import { BaseController } from '../commons/BaseController';
import { BaseUI } from '../commons/BaseUI';

@ApiBearerAuth()
@Controller('/module/sub', { tagName: 'module', description: '模块描述' })
export class XxxController extends BaseController {
  private name = 'xxx_list'; // 模块唯一标识名，影响表单ID和表格变量名

  // ✅ 固定接口 ① —— 路由地址 = Controller路径去掉最后一段（/sub 去掉变 /module/sub）
  @Get('/sub')
  public async getFormUris() {
    return Base.successForm(); // 固定写法，不用改
  }

  // ✅ 固定接口 ② —— formId
  @Get('/sub/formId')
  public async formId() {
    return Base.success(this.name + '_form'); // 如 'xxx_list_form'
  }

  // ✅ 固定接口 ③ —— validate 表单校验
  @Post('/sub/validate')
  public async validate(@Body() body: any) {
    // 无需校验时直接通过
    return Base.success(null);
    
    // 有校验时返回错误信息
    // return Base.success({ errors: { fieldName: '字段名不能为空' } });
    // return Base.success({ errors: { error: '全局错误信息' } });
  }

  // ✅ 固定接口 ④ —— build 构建页面
  @Get('/sub/build')
  public async build(@Query('id') id: string) {
    // 获取数据...
    const data = await this.get(`${Base.ROOT}/resource/${id}`);
    
    return Base.successWrapper(
      /* 页面 UI 树 */ BaseUI.spaceBetween([...]),
      /* JS 函数注入 */ [],
      /* CSS 类 */ ['text-break'],
      /* React 状态定义 */ [],
    );
  }

  // ✅ 提交接口（非固定，但通常叫 submit）
  @Post('/sub/submit')
  public async submit(@Body() body: any) {
    // 处理提交逻辑...
    return Base.success(this.getUrl('/path/to/redirect'));
  }
}
```

## `Base.successForm()` 参数说明

默认参数即为这四个固定方法名，一般不需要改：

```typescript
static successForm(
  formId = 'formId',       // 对应 formId 接口名
  submit = 'submit',       // 对应提交接口名
  validate = 'validate',   // 对应 validate 接口名
  build = 'build',         // 对应 build 接口名
): object
```

## validate 校验返回格式

```typescript
// ✅ 校验通过
return Base.success(null);

// ❌ 指定字段报错（字段名需与表单控件 key 一致）
return Base.success({ errors: { fieldName: '字段不能为空' } });

// ❌ 全局报错（显示在表单顶部）
return Base.success({ errors: { error: '操作失败，请重试' } });

// ❌ 多字段同时报错
return Base.success({ errors: { 
  name: '名称已存在',
  version: '版本格式不正确'
} });
```

## 注意事项

- `this.name` 是整个 Controller 的核心标识，影响：表单 ID、表格选中变量名等
- `getFormUris` 的路由路径 = Controller 根路径（去掉 `/build`, `/formId`, `/validate` 等后缀之前的公共部分）
- 所有跳转 URL 必须通过 `this.getUrl(url)` 包装，确保携带当前项目参数 `?cp=xxx&cl=xxx`
