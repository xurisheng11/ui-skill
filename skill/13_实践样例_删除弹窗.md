# 实践样例：删除弹窗完整模板

包含表格多选 + 确认输入"确认删除"才能提交的安全删除弹窗。

## TypeScript 实现

```typescript
// 在 build 方法中同时返回弹窗和表格
return Base.successWrapper({
  // 1. 删除确认弹窗
  ...BaseUI.tableDeleteModal(
    'my_table',    // tableId
    '资源',        // 资源名称（显示在弹窗标题）
    undefined,     // 自定义卡片标题（不填用默认）
    'name',        // 显示的字段名（默认 name）
  ),
  
  // 2. 表格（带删除按钮）
  my_table: {
    ...BaseUI.tableSelect(header, rows, 1),
    '#header': BaseUI.panelWithActions(
      {
        my_table_button_refresh: BaseUI.refreshButton(),
        my_table_button_delete: BaseUI.deleteButton('my_table', '删除'),
        my_table_button_create: BaseUI.linkButton('创建', url),
      },
      '资源列表',
    ),
  },
});
```

## 后端处理（submit 方法）

```typescript
@Post('/list/submit')
public async submit(@Body() body: any) {
  const ids = this.tableSelected(body['my_table']); // 读取多选行的 id
  
  if (body.op === 'my_table_button_delete') {
    for (const id of ids.split(',')) {
      await this.delete(`${Base.ROOT}/resources/${id}`);
    }
  }
  
  return Base.success(this.getUrl('/module'));
}
```

## 手动构建删除弹窗（更多自定义）

```typescript
// 自定义弹窗内容
const deleteModal = {
  custom_modal: {
    '#type': 'aws_modal',
    '#header': '删除确认',
    '#on_dismiss': "setValue_custom_modal_text('');setValue_custom_modal(false)",
    '#content': BaseUI.spaceBetween({
      alert: BaseUI.alert('确认删除？', '此操作不可恢复！', 'warning'),
      tip: {
        '#type': 'aws_form_field',
        '#label': '输入"确认删除"以确认',
        '#control': {
          custom_modal_text: { '#type': 'aws_input', '#placeholder': '确认删除' }
        }
      },
    }),
    '#footer': BaseUI.box(
      BaseUI.horizontalPanel({
        cancel: BaseUI.clickButton('取消', "setValue_custom_modal_text('');setValue_custom_modal(false)"),
        confirm: BaseUI.button('确定', 'primary', undefined, "value_custom_modal_text !== '确认删除'"),
      }, 'xs'),
      undefined, 'right'
    ),
  },
};
```

## 关键命名约定

| 元素 | 命名规则 | 示例（tableId=my_table） |
|---|---|---|
| 弹窗状态变量 | `${tableId}_modal` | `my_table_modal` |
| 输入框 key | `${tableId}_modal_text` | `my_table_modal_text` |
| 取消按钮 | `${tableId}_button_cancel` | `my_table_button_cancel` |
| 确认按钮 | `${tableId}_button_delete` | `my_table_button_delete` |
| 打开弹窗 | `setValue_${tableId}_modal(true)` | `setValue_my_table_modal(true)` |
| 关闭弹窗 | `setValue_${tableId}_modal(false)` | `setValue_my_table_modal(false)` |
